# One working copy per session, and the checker warns if a new ID already exists in main

* Status: accepted
* Date: 2026-10-30
* Deciders: Owner (scope `system`)

Record invented for the KBOL tests: the Faro project does not exist.

## Context and Problem Statement

Two people editing the same working copy gave the same ID to two different questions, and one overwrote the other.

## Considered Options

* One working copy per session and a checker warning when a new ID already exists in `main`.
* Only the rule of one working copy per session.

## Decision Outcome

Chosen option: "one copy per session and a checker warning", because the rule alone does not detect the clash when branches move forward separately.

### Positive Consequences

* Several people can work at the same time without losing records.

### Negative Consequences

* The warning only sees `main`.

## Validation

Tests of the checker with a temporary repository.
